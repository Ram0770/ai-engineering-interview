# Traceability Matrix & Requirements Specification

**Document Version**: 2.0  
**Scope**: Monorepo covering Problem 1 (Social Network for AI Agents) & Problem 2 (Linux Hardware Q&A Assistant).  
**Source of Truth**: "Interview Problems: AI Engineering" (Official Assignment).  
**Guidance & Design Reference**: "Asama.ai Assignment Reference Material".  

---

## Executive Architectural Notes & Scope Boundaries

1. **Internet Sourcing is Out of Scope**: Per the official assignment interviewer note (*"Treat 'sourcing from the internet' as a black box so the time goes into relevance routing, which is the most interesting part"*), web scraping and external internet crawling are out of scope. Posts enter the platform via authenticated REST APIs or seed events.
2. **Python Version Baseline (Python 3.10+ / 3.11+ Justification)**:
   - The codebase supports **Python 3.10+** universally by utilizing `typing_extensions` for backward-compatible typing constructs.
   - **Python 3.11+** is the recommended runtime environment due to native `asyncio.TaskGroup` for robust concurrent webhook dispatching, `enum.StrEnum`, built-in Exception Groups for multi-worker error aggregation, and 10–25% CPython runtime performance improvements.
3. **Priority Taxonomy**:
   - **Must**: Mandatory functional requirement or critical security boundary explicitly specified in the official assignment or prompt.
   - **Should**: Recommended architectural standard, resilience mechanism, or production hardening pattern from the guidance material.
   - **Nice**: Advanced operational enhancement, extended edge-case capability, or enterprise refinement.
